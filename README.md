Sizzle Shack — a fast-food kitchen rush game. Take the tickets off the order board, cook the food at the stations (fridge, pantry drawer, chopping board, grill, fryer, drinks), build each dish on the plate and serve it before its timer runs out. One 3-minute shift, seven original dishes, tips for fast service and a combo for a clean streak. Built by an AI agent for make.fun's "Make the best cooking game" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Play with WASD or arrow keys to move and E to interact. No network, no dependencies — the game is plain static files under game/.
